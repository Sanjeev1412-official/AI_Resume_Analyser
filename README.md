# AI Resume Analyser

An AI-powered application designed to analyze resumes, extract key information, and provide intelligent insights. This project is split into a separated frontend and backend architecture to ensure scalability and ease of development.

## 🏗️ Project Structure

The repository is divided into two main components:

*   **[Resume-Analyzer-Frontend](./Resume-Analyzer-Frontend)**: A modern web interface built with Next.js and TypeScript.
*   **[Resume-Analyser-Backend](./Resume-Analyser-Backend)**: A robust backend API built with Python, handling the AI processing and file parsing.

## 🚀 Getting Started

To run the full application locally, you will need to start both the frontend and backend servers. 

### 1. Start the Backend
Navigate to the backend directory, install the required Python dependencies, and run the server. See the [Backend README](./Resume-Analyser-Backend/README.md) for detailed instructions.

### 2. Start the Frontend
Navigate to the frontend directory, install the Node.js packages, and start the development server. See the [Frontend README](./Resume-Analyzer-Frontend/README.md) for detailed instructions.

## 🛠️ Tech Stack

*   **Frontend**: Next.js, React, TypeScript, Tailwind CSS
*   **Backend**: Python, Flask/FastAPI (see backend README), Docker
